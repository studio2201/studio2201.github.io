Install

Containers are the supported path today. Native packages coming via packages/install.sh.

Docker (one line)

Replace APP and PORT — e.g. beam / 4401.

docker run -d --name APP \
  -p PORT:PORT \
  -v /mnt/user/appdata/APP:/config \
  ghcr.io/studio2201/APP:latest

Example — Beam:

docker run -d --name beam \
  -p 4401:4401 \
  -v /mnt/user/appdata/beam:/config \
  ghcr.io/studio2201/beam:latest

Helper script

Prints the docker run line (and runs it with --run).

curl -fsSL https://studio2201.github.io/packages/install.sh \
  | bash -s -- beam
curl -fsSL https://studio2201.github.io/packages/install.sh \
  | bash -s -- --run pad

Also accepts the bare form used in READMEs (shows usage + catalog).

Unraid

Each app ships a DockerMan template XML in its repo.

  1. Copy APP.xml to /boot/config/plugins/dockerMan/templates-user/
  2. Docker → Add Container → pick the template
  3. Apply

Shared design system

UI components and backend utilities live in shared-assets.
